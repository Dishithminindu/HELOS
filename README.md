# HALOS: AI-Assisted Dietary Salt Intake Assessment System

HALOS is a research prototype web application designed to collect patient demographic information, 24-hour dietary recall, and monthly food-consumption questionnaire data. It calculates estimated dietary sodium intake and provides a frontend architecture ready for a machine-learning prediction backend.
